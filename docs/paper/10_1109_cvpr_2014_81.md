# Rich Feature Hierarchies for Accurate Object Detection and Semantic Segmentation

## Why this mattered

R-CNN mattered because it made convolutional networks practical for object detection at a moment when detection had largely stalled on hand-engineered feature pipelines. Rather than treating a CNN as only an image-level classifier, Girshick et al. showed that high-capacity CNN features could be applied to many bottom-up region proposals, turning classification-pretrained networks into strong object detectors. The reported jump to 53.3% mAP on PASCAL VOC 2012, more than 30% relative improvement over the previous best result, was not just an incremental benchmark gain: it demonstrated that learned hierarchical visual representations could replace much of the feature engineering and ensemble complexity that had dominated the field.

The paper also clarified a recipe that became central to modern computer vision: pretrain a large neural network on a data-rich auxiliary task, then fine-tune it for a target task with limited labeled data. That transfer-learning pattern made deep detection feasible before large detection-specific datasets were abundant. By combining selective search region proposals, CNN feature extraction, class-specific SVMs, and bounding-box regression, R-CNN was not yet an end-to-end detector, but it established the components and empirical case for deep region-based recognition.

Its influence is visible in the sequence of systems that followed. Fast R-CNN and Faster R-CNN removed major computational bottlenecks and integrated more of the detection pipeline into the network, while later detectors generalized or challenged the region-based paradigm with single-stage and fully end-to-end designs. More broadly, R-CNN helped shift object detection and semantic segmentation from feature-pipeline design toward representation learning, making it newly realistic to build high-accuracy detectors by adapting deep networks rather than constructing task-specific visual features by hand.

## Abstract

Object detection performance, as measured on the canonical PASCAL VOC dataset, has plateaued in the last few years. The best-performing methods are complex ensemble systems that typically combine multiple low-level image features with high-level context. In this paper, we propose a simple and scalable detection algorithm that improves mean average precision (mAP) by more than 30% relative to the previous best result on VOC 2012 -- achieving a mAP of 53.3%. Our approach combines two key insights: (1) one can apply high-capacity convolutional neural networks (CNNs) to bottom-up region proposals in order to localize and segment objects and (2) when labeled training data is scarce, supervised pre-training for an auxiliary task, followed by domain-specific fine-tuning, yields a significant performance boost. Since we combine region proposals with CNNs, we call our method R-CNN: Regions with CNN features. We also present experiments that provide insight into what the network learns, revealing a rich hierarchy of image features. Source code for the complete system is available at http://www.cs.berkeley.edu/~rbg/rcnn.
