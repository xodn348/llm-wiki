# Low-density parity-check codes

## Why this mattered

Gallager’s paper changed coding theory by showing that powerful error-correcting codes did not have to be dense, algebraically rigid objects decoded by prohibitively expensive procedures. By defining codes through sparse parity-check matrices, it made the code’s structure itself computationally useful: the same sparsity that specified the code also enabled iterative, local decoding rules whose complexity grew roughly linearly with block length. This was a conceptual break from treating Shannon’s channel-coding theorem mainly as an existence result. Gallager gave an explicit ensemble with provable linear minimum distance and exponentially decreasing maximum-likelihood error probability under suitable channel conditions, while also pointing toward practical decoders.

The immediate limitation was historical rather than conceptual: the iterative decoder was ahead of available hardware and of the probabilistic graphical-model language that would later make its significance obvious. After turbo codes appeared in the 1990s, LDPC codes were rediscovered and recognized as one of the central routes to near-capacity communication. Gallager’s sparse parity-check construction became the prototype for message-passing decoding on factor graphs and Tanner graphs, linking coding theory to belief propagation and modern probabilistic inference.

What became newly possible was a practical engineering path toward Shannon-limit performance: long block codes with structured sparsity, scalable decoding, and performance close to channel capacity. Subsequent LDPC work refined degree distributions, irregular ensembles, density evolution, and implementation techniques, turning the 1962 idea into a foundation for modern communications standards. Its importance is therefore not only that it introduced a successful family of codes, but that it reframed error correction as sparse-graph inference, a paradigm that shaped both information theory and applied probabilistic computation.

## Abstract

A low-density parity-check code is a code specified by a parity-check matrix with the following properties: each column contains a small fixed number <tex xmlns:mml="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink">j \geq 3</tex> of l's and each row contains a small fixed number <tex xmlns:mml="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink">k &gt; j</tex> of l's. The typical minimum distance of these codes increases linearly with block length for a fixed rate and fixed <tex xmlns:mml="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink">j</tex> . When used with maximum likelihood decoding on a sufficiently quiet binary-input symmetric channel, the typical probability of decoding error decreases exponentially with block length for a fixed rate and fixed <tex xmlns:mml="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink">j</tex> . A simple but nonoptimum decoding scheme operating directly from the channel a posteriori probabilities is described. Both the equipment complexity and the data-handling capacity in bits per second of this decoder increase approximately linearly with block length. For <tex xmlns:mml="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink">j &gt; 3</tex> and a sufficiently low rate, the probability of error using this decoder on a binary symmetric channel is shown to decrease at least exponentially with a root of the block length. Some experimental results show that the actual probability of decoding error is much smaller than this theoretical bound.
